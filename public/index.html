关于刷题计时器

版本：v2.0（MySQL 前后端分离版）

快捷键：空格 = 开始 / 结束计时；单题模式下 Y = 对、N = 错；整组完成面板 N = 标错、Y = 取消、方向键移动、回车完成

技术架构：Node.js + Express + MySQL 后端，原生 HTML / JS 前端；数据全部存储于本地 MySQL 数据库，历史与收藏分页加载，数据再多也不卡。
